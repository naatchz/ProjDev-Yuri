# Explorateur de fichiers

Projet réalisé en Python avec Tkinter par Yuri Lima, SI-C3b.

Cette application permet de parcourir un dossier et de consulter les informations de ses fichiers.

## Fonctionnalités

- Affichage des dossiers et sous-dossiers.
- Informations sur les fichiers : nom, chemin, type, taille, date de modification et permissions.
- Aperçu des fichiers texte et du code.
- Affichage de l’espace disque disponible.

## Utilisation

Avec Python 3 et Tkinter installés, lancer :

Dans le menu **File > display directory**, choisir un dossier, puis cliquer sur un élément pour voir ses informations.
